# Go demo：比较报告后的修复与复核

2026-09-22。本次针对 [原比较报告](../../../test/reports/comparison-20260922/README.md) 中 Go 的失败反例优化 `demo_src_go`。原报告、原评分规则和原 fixture 保留。本报告不重新判定全部 120 条设计用例，也不将短时模型测试计为长期验收。

## 已完成的修复

| 原问题 | 实现与恢复边界 | 验证 |
|---|---|---|
| AUD02：过期普通决定仍能回答 | 回答提交的同一事务内检查 deadline，截止时刻即拒绝；已成功回答的相同请求重投仍返回原收据。定时过期将执行恢复为 READY，让 agent 重新评估，不生成回答或批准。 | 回答先于截止、截止后回答先于维护、维护先于回答三个排列；拒绝不追加 journal。 |
| AUD05：Context 可原位修改 | Context、Checkpoint、Dispatch、TaskResult、ArchiveManifest 为不可变记录；同事务重复保存、后续事务覆盖和 journal 重放中的二次修改均拒绝。 | 原探针；另构造 checksum 正确的非法第二版本，重新打开时拒绝恢复。 |
| AUD12：gate 忽略 epoch/attempt | final gate 核验当前独占 owner、Execution 与 Operation 的 attempt，主会话操作核验 Session。仅在宿主恢复/新 attempt 分配时，对尚未开始的待执行操作显式记录身份交接；gate 不再改身份。 | 有效对照、仅 epoch 错、仅 attempt 错均符合预期；批准后重启/恢复仍只 dispatch 一次。 |
| 失败处理忽略状态落盘错误 | 模型、压缩、程序、文件操作、World 重试和初始化等路径检查状态写入结果；保留原始错误与持久化错误。 | 对普通模型失败及压缩失败同时注入存储故障，确认两个错误都可见，原文及待处理状态仍保留。 |
| 事项退出 Consciousness 后无法找回 | 从持久化原件派生中英文词项索引，支持实体编号、事件精确读取、固定快照分页；主会话按当前问题自动回查最多 12 条、最多约 12KB 原件，再做最终 Context 预算检查。 | 确定性清空摘要事项后重新打开，验证两个联系人原文出现在实际模型 Context；完整 11 问复合问题、分页期间追加事件、空结果不等于从未提供、P-A/P-B 分别命中均有回归。 |

回查内容明确标为不可信历史资料，保留来源、时间和作用域，不赋予批准权限，不写入 World，也不强制普通事项永久留在 Consciousness。索引可由 journal 重建，不能替代原件。检索是词项匹配，不是完备的语义搜索；别名、预算截断和大规模历史仍会影响召回。

## 真实模型短记忆题：保留全部尝试

沿用原 8 条输入、固定顺序、三次主动压缩、关闭后新建 App、11 问及原字面评分规则。使用既有 OpenCode Go 主会话配置；每轮使用独立临时数据目录，不向实际复核会话写入测试对话。独立重复不是 provider 可控 seed，也没有执行预算分桶、无摘要对照或长时回放。

| 版本/轮次 | 原字面评分 | 压缩成功次数 | 观察 |
|---|---:|---:|---|
| 原比较报告 | 9/11 | 3/3 | 两位联系人的角色被答为资料未提供。 |
| 初版检索，最多 6 条：1 | 9/11 | 3/3 | 身份原件排在截断之后；仍未找回。 |
| 初版检索，最多 6 条：2 | 7/11 | 3/3 | 身份未找回，另有字面评分扣分。 |
| 初版检索，最多 6 条：3 | 11/11 | 2/3 | 一次候选遗漏未履行承诺，被拒绝。 |
| 12 条/字节预算版：1 | 11/11 | 2/3 | 身份找回；一次候选引用 hash 格式错误，被拒绝。 |

| 最终实体编号分词修正版：1 | **11/11** | **3/3** | 12 次模型调用；两位联系人身份、历史测量、冲突、时效和未履行承诺均按原评分通过。 |

初版完整答案见 [初版评分](memory-scores.json)、[运行清单](memory-runs.json)。12 条版见 [逐字段评分及阶段错误](final-memory-scores.json)、[对应生产源码 hash](final-memory-sources.json)。上述两处措辞差异不修改原分数；人工阅读认为事实与约束一致，不将其改写成自动 11/11。

最终实体编号分词修正后的独立确认见 [评分](entity-memory-scores.json) 与 [生产源码 hash](entity-memory-sources.json)，运行期间源码未变。所有模型输出与压缩阶段错误保留在对应 `*-N.json`；任何一次进程退出 0 都不代表语义或三次压缩全部成功。

校验失败的压缩候选没有提交；旧 Consciousness 与未覆盖原文仍在。最终代码的一轮确认完成三次压缩及 11 问；前述候选版本的压缩拒绝仍是有效限制证据。**不能凭这一轮证明模型稳定产出合法压缩或长期胜率**。确定性“普通身份事项完全退出摘要后仍能回查”的证据来自 `history_test.go`，不依赖模型恰好忘记。

显式复测（会调用付费模型，凭据仅从已导出的私有环境读取）：

```sh
python3 scripts/verify-memory.py --attempts 3 --label review-memory
```

脚本拒绝覆盖已有同名报告，默认正常 `go test` 不触发模型。`--score-only` 只重算已有输出；score-only 的源码一致性字段只描述评分执行期间，不证明历史模型运行源码。
