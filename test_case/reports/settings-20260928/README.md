## 浏览器验收

通过 CUA 操作隔离 fixture WebUI，使用合成数据：同一草稿创建实体及姓名事实，应用后为 ACTIVE；更正姓名并撤回，历史分别显示 SUPERSEDED 和 RETRACTED；提交负数身高得到 FAILED / INVALID_FACT_VALUE，恢复失败草稿、移除错误并改为 170 后成功；Secretary 说明保存草稿、应用、重新加载后有效版本为 r2。窄屏截图已人工检查，入口可见且可操作。

浏览器服务在部分后端修正前启动；最终后端状态以最终完整运行回归为准。此项是 fixture UI 操作证据。没有对现用服务做浏览器验收。
