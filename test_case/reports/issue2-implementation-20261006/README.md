- 当前计数为保守 UTF-8 字节估算和协议余量，非精确 tokenizer；尚未建立跨 provider/template 的自适应计数校准。服务 usage 是对应请求观测，不能混作下一请求预测。
- 保留原始输入、未完成承诺和活跃工具协议对存在不可压缩下界。超出容量时可恢复阻塞；不保证任意长会话总能压到目标比例。
- 已覆盖 C01–C20 中的具体边界，但不是该矩阵所有排列的穷尽验收；跨供应商、超长真实语义质量、长期成本、饥饿极限及全链路性能仍有未验证部分。
- 无内部身份标记的歧义历史记忆头可能保守保留多项；不会按文本猜删真实输入。已标记的新头在 JSON/CAS 往返和多次投影中保持一份。
