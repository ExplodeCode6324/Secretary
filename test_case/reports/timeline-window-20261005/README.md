# Web 历史窗口验收摘要

日期：2026-10-05。Web 状态接口支持有界时间线窗口，不返回聊天正文；历史活动复用活动索引。客户端限制缓存条数、字节数及 DOM 节点，分页与定位使用稳定游标；设置变化、断线和多客户端并发时丢弃过期响应。

## 验证

- 完整离线回归：167 项中 162 通过、5 项 PostgreSQL 用例按既有条件跳过、0 失败；补充 13 项边界用例和 emoji 分段用例通过。
- 审计回归 36/36；混合顺序 oracle 覆盖分页、定位、迟到工具、授权归属、UTF-8 字节预算、旧协议和大正文分段还原。
- 合成 Chrome 验证 6000 项历史翻页、四种流式/思考设置、断线恢复、390px 布局、草稿/光标和锚点保持；另有双客户端竞态与十分钟合成持续测试。
- 长历史性能数据见 [performance-final.json](performance-final.json)。本机合成数据 1千/1万/10万条时，API 深页查询 P95 约 7.8–9.2ms（单客户端），四并发约 29–35.6ms；浏览器定位渲染 P95 约 24–25ms。

这些数据是本机 Store 与合成浏览器负载，不是 PostgreSQL 压测或跨机器 SLA。索引构建、Store 重放和单条大消息读取仍会随历史规模增加；未声称无限历史成本恒定。原始失败调试日志和本机路径信息不公开。
