- 本机运行配置、模型密钥和备份均未提交 Git。自定义会话隔离规则见[运行手册](../../../docs/operations.md)。

- 关闭后台：`npm run stop`；数据库保持运行。需要全部停机时，再执行 `pg_ctl -D .demo-data/world-postgres -m fast -w stop`。重新运行原 live 启动入口可恢复两者。
