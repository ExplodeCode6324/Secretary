## 数据恢复点

应用前的完整备份路径仅记录在本机，不纳入公开报告。恢复前须正常停共享后台并先另存应用后的数据；不能在后台持有 owner.lock 时替换目录，也不能覆盖应用之后新产生的输入。源代码恢复应只撤销本次记忆改动，避免覆盖其他并行开发改动；`source-before/` 为修改前参考快照，非整仓回滚脚本。
