# Secretary 自定义说明复核 · 2026-09-23

已实现独立说明设置、持久化、每轮固定快照、旧 system 刷新，以及 Context 版本追踪。
原有固定职责提示词正文没有改写；新增的说明解释其默认偏好语义，不改变宿主授权。

## 使用

双击 demo_pi 下的「启动Secretary_Web.command」，左侧点击「Secretary 说明」。
默认内容是简体中文、称呼 Master、回答简洁、技术名称保留原文。可修改或清空；保存后下一轮生效。
当前轮不会被中断；设置页显示当前轮、最近使用和下轮配置版本。

## 一致性与恢复

唯一写入来源为 journal 内 `UserInstructions`，不会与 World Model 双写。
后台保存校验 expected_revision，无 await/远程数据库操作；保存不等待模型、Scheduler 或记忆整理。
每轮提示词快照与输入 CLAIMED 一起提交，保存失败不返回成功。同轮所有模型请求与重启恢复共用快照；新轮使用最新说明。
历史 raw Context 保留；不会通过清空上下文实现刷新。配置对象损坏时 Store 校验失败，不能静默改成空说明。

说明不是 World Model 的事实，也不由 Consciousness 维护。主会话新 system 附带当前工具声明，任务和整理的专用 system 不注入本设置。

## 部署与回退

`deployment.json` 记录运行数据备份目录、后台 PID、应用时间及配置版本。部署前主会话 IDLE，输入全部处理完毕，任务全部终态。
安全停止旧后台后备份运行目录，再启动新后台；没有创建生产测试消息，没有清空会话、记忆或任务。
旧浏览器地址/token 可能失效，请重新双击 Web 启动器打开。

本次扩展了 journal 合同类型。若回退代码，必须同时使用部署前数据备份，不能用旧 schema 直接读取已写入新类型的数据。
回退前应保留当前目录，避免丢弃部署后新增对话；本次没有执行回退。
