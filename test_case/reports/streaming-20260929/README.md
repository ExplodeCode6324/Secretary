# 流式输出与思考显示验收

2026-09-29，Master 批准实施，并指定默认“流式开、思考开”。已实现并应用到现用 live 实例。

## 结果

- 主会话 WebUI 通过 SSE 接收真实增量；显示开关独立、按浏览器保存，支持运行中切换。
- 思考内容仅取供应商返回的可见文本或摘要；思考字号 12px，正文 14px，沿用暗色主题，支持折叠。
- Agent 仍在完整响应保存成功后才获得响应；展示通道不授予权限、不执行工具、不回写模型上下文。
- 当前实例空闲时完成重启，session 和原 journal 前缀保持一致，新静态资源和 SSE 已确认生效。
