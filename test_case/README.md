## 后续记忆回归框架

#21/#28 的联合验收将扩展真实模型记忆场景：多轮形成事实、后续更正、上下文退出、整理和重启、长期未完成事项，以及从原始日志检索证据。

每个场景保存原始证据和预期状态，运行正常记忆链路，记录首次回答、检索结果、派生记忆及模型配置。失败时，可将正确原始证据直接放入同一模型 context 再测，以区分来源缺失、检索遗漏、记忆生成/退出和阅读推理问题。模型或记忆结构升级时，比较直接读取旧记忆与从原始记录重建后的结果。

当前已有真实整理与跨进程连续性场景；框架扩展随相关功能交付。离线测试验证状态与协议，真实模型测试记录语义质量及样本差异。
