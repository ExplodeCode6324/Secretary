# 原始设计归档

这里保存设计阶段的原始设计和早期实现说明，和当前代码不构成证据对应。内部旧命令、路径、状态表、source hash 与完成结论只解释原来的设计或验证现场，不是当前操作入口。引用 Go 实现的设计已清理，不再作为开发依据。

- `demo_design/`：原始模块、接口、持久化与实施计划。
- `json/`、`schema/`、`state_machine/`：当时设计契约副本。运行时只加载 `src` 中的有效契约。
- `test/`：原始测试设计、静态检查脚本和未运行用例目录。它们不属于当前可执行回归；历史来源指纹不重新签发为当前证据。
- `implementation-notes/`：旧 Pi 使用说明，不作为当前运行手册。

测试报告集中于 [reports](../../test_case/reports/README.md)。当前开发与启动请从 [文档索引](../README.md) 开始。
