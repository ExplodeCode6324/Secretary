# 原生客户端设计 v0.3

2026-10-10 确认的设计方向，2026-10-12 按当前 Core 能力整理。SwiftUI 页面由 #10 实现；本文记录待实现的界面规格。Core 已提供显示名、任务、Scope、记忆、产物、设置、关联和待处理 API，#9 将补齐可靠同步。

## 页面与导航

macOS 系统窗口控制保持原生。内容顶部左侧为普通文字助手名称，使用 Core display_name，空白回退 `secretary`；名称兼作返回对话入口。右侧按顺序排列“任务　记忆　设备　产物　设置”，下方一条细横线。页签采用平直矩形、细边框和极小圆角，选中状态同时通过边线与可访问性属性表达。

名称单行截断，悬停或聚焦显示全文。窄窗和放大文字时，超出宽度的栏目按原顺序收进“更多”菜单。返回对话恢复草稿和阅读位置，“回到最新”单独控制滚动。顶部在需要处理审批、决定或连接问题时显示简短状态。

## 字体与布局

以下为首版 macOS 逻辑 pt 起点，随真实窗口验收微调。

| 项目 | 默认值 |
| --- | --- |
| 初次内容尺寸 | 1280 × 860 pt，后续恢复用户尺寸 |
| 最小内容尺寸 | 720 × 520 pt，支持内容滚动与导航折叠 |
| 水平外边距 | 20 pt，紧凑窗口 16 pt |
| 顶部导航 | 内容高约 40 pt |
| 助手名称 | 系统字体 16 pt，中等字重 |
| 对话正文与编辑文字 | 13 pt，行高约 1.5 倍 |
| 栏目、按钮、旁栏 | 12 pt |
| 作者、时间、紧凑状态 | 11 pt；审批和错误说明用正文级字号 |
| 代码 | 12 pt 等宽；代码块和宽表格局部水平滚动 |
| 输入框 | 初始约 3 行、64–72 pt；最大约内容高度四分之一，之后内部滚动 |

对话占据顶部和输入区之外的主要空间。右栏默认 **200 pt**，可在 180–220 pt 调整或手动收起；对话使用剩余宽度。两栏间细竖线，右栏内边距约 12 pt，对话侧约 16 pt。默认字体下对话剩余宽度少于约 800 pt 时自动收起右栏，放大字体按内容需求调整。

1280 pt 窗口在总外边距 40 pt、右栏 200 pt、分隔线 1 pt 下，对话约 1039 pt；1440 pt 时约 1199 pt。1024 pt 默认收起右栏，对话约 984 pt。自动折叠保留手动偏好，“相关内容”入口可临时打开面板。

字号、窗口、旁栏宽度与显示偏好保存于客户端本地。

## 对话与关联内容

每条记录先显示作者与时间，下一行展开正文。Master 用杏色、左侧细竖线与少量缩进；助手署名用淡蓝色，正文沿统一阅读轴展开。轮次用留白区分，日期或大分组可用细横线。Markdown 正常显示标题、引用、列表、代码和表格。

作者类别与显示名分别保存；模型回复、任务反馈、系统事件和设备观测使用各自来源与资源 ID。空对话留白，输入区可直接使用。

右栏按“任务、产物、设备”分节，每节默认最多 5 条，“查看全部”进入同筛选条件的完整页面。关联范围由当前对话或用户明确选中的任务、消息、事件决定；普通滚动保留范围。定位记录使用服务端 ID 与周边窗口，读取失败显示对应原因。

## 完整页面

| 页面 | 内容 |
| --- | --- |
| 对话 | 消息、活动、输入队列、流式/可见思考开关和相关内容 |
| 任务 | 任务与执行列表、Scope、详情、接续、取消、审批和工作决定 |
| 记忆 | 工作记忆摘要、承诺、补提状态，World 实体、事实与来源；World 修改共用 Settings 草稿 |
| 设备 | 列表、状态来源、观测时间与新鲜度；#14 提供标记清晰的模拟展示，真实能力随 #11 接入 |
| 产物 | 分页、任务筛选、详情、下载/打开，按 artifact ID 和内容版本识别 |
| 设置 | 显示名、有效说明、草稿和应用进度；连接及本地偏好分组呈现 |

待处理入口显示“待审批 1”“待回答 1”等短文字，窄窗和其他页面也可进入。审批展示操作、参数与期限，使用“批准／拒绝／撤销”；工作决定使用“提交回答”。用户实际打开执行详情提交 viewed，后台刷新保持读取行为。

## 输入与请求状态

输入区固定在对话栏底部，上方细横线。多行编辑框背景略亮、边界清楚、2–3 pt 圆角；空框留白，VoiceOver 标签为“消息输入”。右下“发送”按钮为杏色底深色文字。阅读动作使用带细底线的文字链接，提交动作使用朴素矩形按钮。

Return 换行、⌘Return 发送；输入法组合中保留编辑。有效输入进入持久 outbox 后清空编辑框，失败时保留草稿。草稿和阅读位置按 Core 数据域及对话保存。

发送状态为待发送、发送中、已受理、未确认或失败。超时请求按原 ID 对账，恢复已保存的发送意图。活动发生时显示处理中、排队或等待审批；详细容量信息放在记忆页或可展开状态。附件和语音按钮随实际能力接入。

| 主背景 / 辅助背景 / 次级表面 | #191B1D / #141618 / #222527 |
| 装饰分隔线 | #303336 |
| 普通文字 / 次要信息 | #E3E3DF / #929996 |

不透明 sRGB 计算中，正文与次要文字对主背景约为 13.42:1、5.94:1，输入边界约 3.57:1。装饰线用于分隔，操作状态另有文字、焦点和选中标记。验收包含字号放大、足够点击区域、完整键盘路径、VoiceOver 与系统对比度设置。

## 能力、数据与同步

组件分别记录客户端页面实现、服务端 capability、操作许可、连接状态和数据状态。数据可处于 not_loaded/loading/empty/ready/error，并同时带 cached/stale 与最后确认时间。请求失败可与已有缓存一起显示，恢复后刷新。

Core 提供同一实体的 ID、revision、查询和写入合同；客户端复用它们维护跨页状态。#9 接入名称、记忆、产物、Scope、规则、裁定、关联与待处理内容的变更收敛。设备观测将使用来源、观测/接收时间和新鲜度。

## 验收安排

- 在真实 macOS 检查默认、宽窗、1024 宽、最小尺寸、分屏和放大字号，核对对话宽度与右栏折叠。
- 检查长名称、导航、窗口控制、键盘和 VoiceOver。
- 检查草稿、阅读位置、输入法、持久 outbox、响应丢失、原 ID 对账与进程重启。
- 检查审批、工作回答、未知结果和普通阅读的实际命令；后台刷新与显式 viewed 分别验证。
- 检查记忆与 World 修改、产物重名/分页/下载、关联定位，以及离线缓存、空数据和错误恢复。
