# 客户端页面、组件与行为规范 v0.3

日期：2026-10-10。状态：**已确认设计方向 / 规划文档 / NOT_IMPLEMENTED / NOT_UI_TESTED**。

依据 Master 的《客户端页面与组件描述 v0.2》及后续确认：保留简洁的文字导航、连续阅读区和旧 WebUI 色彩；字体更小、对话区域更大，取消固定三比一分栏。本文是 [#7 原生迁移路线](https://github.com/ExplodeCode6324/Secretary/issues/7)的设计依据，不代表已完成客户端或后端实现。

## 1. 页面身份与导航

- macOS 系统窗口控制区域保持原生行为，应用内容从其下方开始，不重复绘制交通灯或把可点击栏目放入窗口拖动区。
- 顶部左侧只显示助手名称。使用 Core 公开的显示名称，去除首尾空白后为空则回退小写 `secretary`；不从提示词、模型正文或设备名称中猜测。
- 名称为普通文字标题，兼作返回对话的入口；不配头像、首字母图标、徽标、装饰符号、副标题或独立品牌区域，正文上方不重复名称。用户界面不显示“主会话”字样，内部协议仍可使用 session 等技术标识。
- 同行右侧排列：**任务　记忆　设备　产物　设置**。顶部紧凑，下方细横线贯穿内容区；页签使用平直矩形、细边框和极小圆角，选中项有清楚的边线变化与可访问性选中状态，不能只靠色相差别。
- 名称单行显示，过长时截断，悬停或聚焦可查看完整名称；不挤压导航。默认五个栏目直接可见，窄窗或放大文字后装不下时，把装不下的栏目收进文字“更多”菜单，保持顺序、当前页状态和完整键盘访问，不强行缩小字号。
- 点击名称返回对话恢复原阅读位置与草稿，不隐式跳到最新、不提交输入。只在用户明确“回到最新”时滚动到底部。
- 顶部没有欢迎语、介绍、模型参数和常驻使用提示。需要处理的审批、工作决定或连接异常可用短文字显示，直到处理或解除。

## 2. 尺寸、字体与对话区域

以下是首版实现起点，单位为 macOS 逻辑 **pt**，不是截图像素；需在真实 macOS 上验收后微调，不能把这些数值当成已验证的显示效果。

| 项目 | 默认设计值与规则 |
| --- | --- |
| 初次窗口内容尺寸 | 1280 × 860 pt；受屏幕可用范围约束，后续恢复用户窗口尺寸，不在每次启动重置 |
| 最小窗口内容尺寸 | 暂定 720 × 520 pt；放大文字时必须允许内容滚动或导航折叠，不能裁掉操作 |
| 内容外边距 | 水平 20 pt，紧凑窗口可减至 16 pt；不设置占用大量空间的品牌留白 |
| 顶部导航 | 内容高约 40 pt，不包含系统标题栏；文字视觉紧凑，实际点击区域不随文字缩成细线 |
| 助手名称 | 系统字体，默认 16 pt，中等字重 |
| 对话正文与编辑文字 | 默认 13 pt，正常字重；行高约 1.5 倍，保持中文、引用和列表清楚 |
| 栏目、按钮、旁栏条目 | 默认 12 pt；依靠间距与字重区分层次，不放大成大标题 |
| 作者、时间、紧凑状态 | 默认 11 pt；关键错误/审批正文仍用正文级字号，不能藏在极小附注里 |
| 代码 | 默认 12 pt 等宽字体；代码块和宽表格在自身范围水平滚动，不撑坏全窗口 |
| 输入框 | 初始约 3 行、约 64–72 pt 高；随内容增长，最多占内容区域高度的约四分之一，之后内部滚动 |
| 对话阅读区 | 占据顶部与底部输入区之外的主要空间；不再嵌入狭窄居中卡片或额外大内边距 |

字体可在客户端设置中放大并保存；这些是默认值，不是上限。字号、窗口尺寸、旁栏宽度和显示偏好属于客户端本地偏好，不写入助手记忆或业务 Settings 生效流程。

### 分栏规则

- **取消固定三比一比例。** 对话区获得全部剩余宽度，右栏默认仅 **200 pt**，包括其内边距；可在 180–220 pt 间调整，也可手动收起。
- 两栏以一条细竖线分隔；右栏每侧保留约 12 pt 内边距，对话区与分隔线之间保留约 16 pt 阅读间距。
- 在默认字体下，若剩余对话栏不能达到约 800 pt，则自动收起右栏。放大文字时根据实际内容需求更早收起，不硬压正文。
- 按水平外边距总计 40 pt、右栏 200 pt 与分隔线 1 pt 计算，1280 pt 窗口中对话栏约 1039 pt；1440 pt 中约 1199 pt。1024 pt 中默认收起右栏，对话栏约 984 pt。栏内间距再从相应栏内扣除。
- 自动收起不覆盖用户的手动偏好。需要时用文字“相关内容”入口在面板中临时查看，关闭面板恢复正文；收起不丢失待处理提醒。
- 宽窗、窄窗、分屏与放大字号都保持同一阅读轴；增大窗口优先扩大对话空间，右栏不按窗口比例膨胀。

## 3. 对话与关联旁栏

每条记录先显示作者与时间，下一行展开正文。Master 用杏色标识并保留左侧细竖线与少量缩进；助手署名用淡蓝色，回答沿阅读区自然展开，不做大面积气泡。

所有消息沿同一阅读轴排列；轮次用适量留白分开，日期或大的内容分组可用细横线。正文保留标题、段落、引用、列表、代码、表格的正常排版。空对话保持留白，输入区立即可用。

作者身份与显示名称分开：模型回复、任务反馈、系统事件与设备观测保留自己的来源类别和关联 ID。更名不会把设备或工具输出变成 Master 发言；姓名只是展示字段。

关联旁栏只包含“任务”“产物”“设备”，每节简短标题、细横线和条目，不重复导航：

- 任务：名称及必要状态；产物：可打开文件名，重名时补充任务或时间；设备：名称及有观测依据的状态，陈旧时明确标示。
- 默认范围是当前对话明确关联的资源。用户明确打开或选中某个任务、消息/事件时，可切换关联范围；普通滚动不改变范围，不能让旁栏随滚动跳变。
- 关联来自 Core 的已记录关系和稳定资源 ID，不按正文关键词匹配、不为了旁栏调用模型、不要求客户端扫描全部任务历史。
- 每节默认最多 5 条，服务端查询有界；存在更多条目时显示“查看全部”，进入带相同筛选条件的完整页面。没有关联数据的节可以收起，空状态与读取失败仍按第7节区分。
- “定位记录”使用服务端消息/事件 ID 与有界周边窗口；归档、删除、不可访问或超出可读范围时返回明确结果，不盲目翻页到全历史。

## 4. 完整页面与待处理入口

| 页面 | 首期内容与边界 |
| --- | --- |
| 对话 | 对话、活动、输入队列及当前相关内容；活动只在实际发生时显示必要短状态，保持流式/可见思考开关与稳定消息合并 |
| 任务 | 任务和执行列表、详情、接续、取消；顶部集中列出待审批与普通工作决定，二者分别呈现 |
| 记忆 | 只读工作记忆摘要、承诺与更新/恢复状态，以及 World 实体/事实与来源记录。摘要不开放任意编辑；World 修改经现有共享草稿和 apply，复用 Settings 冲突与恢复规则 |
| 设备 | 设备列表、详情、状态依据与新鲜度；#14 提供明确标记的模拟展示，#11 等真实后端就绪后按能力开放实际操作 |
| 产物 | 独立分页列表、任务筛选、详情、下载/打开；按 artifact ID 和内容版本识别，不按文件名或设备绝对路径读取 |
| 设置 | 助手显示名称、有效说明与草稿/apply/恢复；连接和本地显示偏好另分组，明确本地立即保存与 Core 业务配置的生效区别 |

工作记忆、World 与设置可以互相定位，但同一实体使用同一 API 和版本；不能在不同页面维护两份编辑或生效状态。

- “任务”栏目旁按需显示“待审批 1”“待回答 1”等短文字，其他页面及旁栏收起时也可见。窄窗导航折叠时，该待处理入口仍独立可达；处理后更新或消失。
- 权限动作写“批准／拒绝／撤销”，普通决定写“提交回答”；必须展示实际操作与参数、截止状态，不能全部简化为“确认”。
- 查看、展开、定位、通知展示或已读不自动批准、不回答决定。只有明确操作才提交原 request ID 与服务端授权/恢复 binding。
- 后台刷新不续留任务；用户真正打开执行详情才提交显式 viewed。重复渲染、窗口恢复和消息重放不能反复提交访问命令。
- 本地待处理计数是服务端状态的投影；离线时显示最后确认状态与时间，不伪报已处理。未确认写请求通过原 ID 对账。

## 5. 链接、按钮与输入

查看任务、打开产物、定位记录等阅读动作使用带细底线的文字链接。发送、保存、应用等提交动作使用朴素矩形按钮；发送按钮写“发送”，杏色底和深色文字。操作文本表达真实效果，打开文件不包含执行脚本。

输入区只属于对话页，固定在主阅读栏底部，上方细横线与记录区分开。编辑区为多行文本、略亮背景、清楚边界、2–3 pt 圆角；空框无可见占位提示，但提供“消息输入”的可访问性标签。发送按钮位于下方右侧。

- 默认 Return 换行、⌘Return 发送；中文输入法仍有组合文字/候选时不发送。快捷键可由应用菜单发现，不常驻输入区。
- 空或仅含空白的输入不能发送，失败不清空原稿。草稿与阅读位置按 Core 数据域和对话保存，栏目切换、返回对话及客户端重启后可恢复。
- 发送意图进入持久 outbox 后，文字作为该消息的内容保留；编辑框可清空以写下一条。不得先清空唯一副本再尝试持久化。
- 显示“待发送／发送中／已受理／未确认／失败”等必要状态，HTTP 超时归“未确认”并按原 ID 对账；不以新 ID 自动重发可能已受理的消息或操作。
- 在实际活动、排队或阻塞时显示“处理中”“排队 2”“等待审批”等短状态及必要跳转；没有活动时不占固定介绍区域。上下文/记忆容量详情放记忆页或可展开状态，接近限制并影响操作时给出可见提示。
- 附件、语音只预留布局扩展位，未接入时不显示按钮；本轮不新增上传、转写或音频协议。

## 6. 颜色与可访问性

沿用旧 WebUI 色板，不沿用其旧协议：

| 用途 | 颜色 |
| --- | --- |
| 主背景 / 辅助背景 / 次级表面 | `#191B1D` / `#141618` / `#222527` |
| 装饰分隔线 | `#303336` |
| 普通文字 / 次要信息 | `#E3E3DF` / `#929996` |
| Master / 主要提交按钮 | `#FFD7AF` |
| 助手名称、署名、链接 | `#AFD7FF` |
| 系统信息 / 权限审批强调 | `#AFD7D7` / `#FFFFAF` |
| 输入框默认识别边界 | 起点 `#69737B`，需实际显示验收 |
| 选中或键盘焦点 | 淡蓝色清楚线条，焦点可用约 2 pt 描边；不改变普通装饰分隔线 |

按不透明 sRGB 色值计算：正文对主背景约 13.42:1，次要文字约 5.94:1；装饰线对主背景仅约 1.36:1，不用作输入框或当前选中状态的唯一线索。建议输入边界对主背景约 3.57:1、对次级表面约 3.19:1；实际透明度、抗锯齿及系统增加对比度模式仍需验证。

只在特别关注的状态使用明显强调色；普通状态写成短词。颜色不能成为区分身份、选中、失败或权限状态的唯一方式。保持键盘焦点、选中状态、VoiceOver 标签、字号调整和足够点击区域；视觉紧凑不等于缩小点击区域。

参考：[Apple 无障碍指南](https://developer.apple.com/design/human-interface-guidelines/accessibility)、[W3C 非文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。后者用于设计检查参考，不要求所有装饰线加亮。

## 7. 内容、能力与状态

可见文字主要表达身份、内容、操作和状态；“点击这里查看”“功能正在建设中”等介绍不常驻。需要详细原因时可以展开、悬停或键盘聚焦查看。

不得以一个 loaded/disabled 布尔值表示全部情况。组件分别维护以下维度，允许同时存在：

| 维度 | 例子与含义 |
| --- | --- |
| 客户端实现 | 页面已实现或仅预留；这是客户端能力，不能由后端开关凭空变出页面 |
| 服务端能力 | supported、not_supported、not_configured；未知能力默认不开放操作 |
| 操作许可 | allowed 或具体 denial reason；来自已认证服务端，提交时仍重新检查 |
| 连接 | online、reconnecting、offline；与业务状态分开 |
| 数据 | not_loaded、loading、empty、ready、error，以及是否有 cached/stale 数据和最后确认时间 |

- 未实现栏目可保留位置并呈明确禁用态，通过悬停/可访问性说明短原因；不能进入可点击但全空白的正式页面，也不用持续加载动画伪装未实现。
- “未接入”只表示实际未配置的数据源/设备，“暂无记录”只用于成功读取且确实为空。已实现能力的首次读取可以短暂显示“读取中”；失败、重连、离线或缓存陈旧使用对应状态，不显示为空。
- 普通请求加载完成后恢复安静；影响操作的错误或未确认结果持续到解决。错误可以与缓存内容同时显示，不能用缓存掩盖失败。
- 内容、状态和动作入口在组件中分开；预留展示边界不等于预建未授权设备操作或未来音视频后端。

## 8. 接口归属与同步

| 需要的合同 | 归属与范围 |
| --- | --- |
| 显示身份 | #8 提供 display_name、revision 与修改操作，空白归一回退 secretary；稳定 actor 身份与名字分开。仅修改显示名称不触发模型或记忆重建；若另行修改人格/业务说明，仍走既有 Settings apply |
| 能力与操作状态 | #8 返回服务端能力及必要原因码；本地页面实现、字体和布局状态由 #10 管理。权限不是页面可见性，服务端每次执行仍校验 |
| 记忆公开读模型 | #8 公开只读摘要、承诺、更新状态和可定位来源；复用 World 查询及其独立版本，不透传内部 PromptSnapshot、整个 Store 或凭据 |
| 产物目录 | #8 增加分页列表与任务筛选、资源 ID、内容版本、可读取状态；复用已有单产物 metadata/content 入口 |
| 关联与记录定位 | #8 提供明确的 session/task/message/event 范围、有界关联资源及稳定关系依据；提供按消息/事件 ID 读取周边窗口的入口 |
| 待处理摘要 | #8 复用审批/决定状态生成计数和有界列表，带版本与权限范围；不创建第二份待处理状态机 |
| 变更收敛 | #9 覆盖名称、记忆公开投影、产物索引、关联及待处理状态的变更/失效通知；有界刷新、不扫描全历史，接续 revision/cursor，旧事件不能覆盖新状态 |
| 设备事实 | #11 提供来源、观测时间、接收时间、新鲜度与可用动作；#14 验证模拟/真实域隔离、设备详情和状态显示。普通 UI 查询不触发模型 |

上述为合同要求，准确路径和字段由 #8 fix 计划及后续 schema 冻结；暂不实施的设备能力只预留结构，不制造虚假的支持状态。

## 9. 实施验收清单

- [ ] 在真实 macOS 下检查 1280×860、1440×900、1024×768、最小尺寸与分屏；右栏不按三比一占宽，对话始终优先。默认小字与放大字号均清楚，操作无裁切。
- [ ] 超长/空白/未设名称、顶部导航折叠、旁栏收起/恢复、原生窗口控制、键盘导航和 VoiceOver 有对应验证。
- [ ] 页面切换和进程重启保留草稿与阅读位置；选中文本、展开详情和历史阅读不被新消息强制打断；中文输入法不误发送。
- [ ] 空白输入、outbox 持久失败、响应丢失、原 ID 重试、未确认与失败、Core/客户端重启分别覆盖，不丢草稿或重复提交。
- [ ] 待审批/待回答在其他页面、窄窗和旁栏收起时仍可发现；查看、已读、提交决定和批准权限分别验证，不混淆回执。
- [ ] 记忆只读摘要与 World 草稿修改正确分工；产物分页、重名文件、下载/打开和定位原记录不扫描全部历史。
- [ ] 关联范围仅随明确选择变化，普通滚动不跳变；后台刷新不延长任务留存、不新增模型调用。
