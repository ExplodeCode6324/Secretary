## Atomic-fact scoring v2 for the three public questions

1. A new config v3, protocol secretary-answer-atomic-facts-v2, and a separate v2 public package select the schema, audit rules, fixed prompt and controls explicitly. Unknown schemas fail. 2. A question has a scope at the time asked, required/must-not-contradict/optional atomic propositions, stable IDs, aliases or permitted format/quantity variants and units/tolerance where needed.
