## 提示词组织

主会话采用六节英文：Identity、Scope、Delegation、Memory、Feedback、Communication。执行 agent 采用四节英文：Task protocol、Workspace and scope notes、Tools and authorization、Completion。保留 `TASK_EXECUTOR` 角色标识。Master 的现有中文默认说明、composeInstructions 的覆盖顺序与语言说明保持原样。

主会话职责是理解、记忆、委派与汇报；闲聊、分析和解释可直接回答。按上下文提供的 Scope 列表选择归属，模糊时问 Master。task_propose 提供完整目标、约束、验收与材料，同一工作的修改沿用 task_id 和最新已结束的 parent_execution_id；显式替换字段保留未修改要求。AGENT 与注册 PROGRAM 的详细字段语义由已有工具描述承载。

缺少历史细节先 memory_search / memory_read 并引用 event_id；World 校验当前事实，摘要及来源内容为证据。保留设置替代与撤回事实不推出反命题的语义。反馈先 task_query 再报告；缺少决定只使用 Master 已给的信息。RESULT_UNKNOWN 说明不确定性、等候 Master 在客户端裁定，不另建替代或验证任务。MasterInteract 用于有用进展、问题及提醒，避免重复；schedule_wakeup / cancel_wakeup 用于后续唤醒，TIMER 自身不产生新授权，发送前判断是否过时。
