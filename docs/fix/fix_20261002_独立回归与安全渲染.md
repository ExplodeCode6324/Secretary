# 独立回归与安全渲染

本轮从 `fb320a5561a1f1a484f3ecd51914773224e8346a` 独立实施。此前未提交实现已隔离并保存完整恢复归档，旧测试结果不作为本轮验收证据。Master 已授权实施、完整测试，以及使用现有 opencode-go / deepseek-v4.1-flash 对合成场景进行有界在线验收。

## 范围

1. 对干净基线重新运行类型检查、离线运行时、审计和隔离 PostgreSQL 测试。检查双 UI 测试进程清理，区分环境启动失败与清理失败。仅停止本轮创建的测试进程。
2. 新建显式 online 入口，使用真实主模型完成合成逻辑多日输入、事实更正、干扰、重复整理、重启与语言设置变更。场景期望值与问句分离，保存状态、原始失败、调用和费用字段。逻辑日不代表实际跨日运行。
3. 根据本轮重新观察到的失败决定最小生产记忆或提示修复。没有新失败证据时，不为旧报告中的结论改动核心。
4. WebUI 以有限 Markdown 语法呈现结构化内容。输出只来自受控标签与转义文本，链接限制协议，原始 HTML 不执行。完成态与流式预览使用同一安全边界，并验证窄屏和恶意输入。

## 验证边界

在线每轮最多 24 个真实请求、15 分钟；只用合成数据，不运行任务调度或外部动作。现有凭据只用于已授权 provider，不进入日志、补丁或报告。报告保留失败与未执行项目，模型费用字段不等同于到账账单。

原仓库中能逐文件归属于旧任务的改动才可替换，替换前核对源文件仍等于封存版本。其余资料保留。不得部署、推送或启动生产服务。macOS 验证与 Linux 清理分支测试分开报告，未经真实 Linux 执行不宣称云端通过。

## 根据本轮证据实施的修复

真实基线回答把缺少模型侧写记忆工具解释为没有持久化存储，而 Host 已持久记录输入和回答。因此基础提示补充真实的 Host 记忆能力，同时明确持久记录不保证每个细节都在当前摘要中，不承诺完美回忆。

强化账本检查后发现新承诺没有被提取。进一步核对实际整理请求确认：`main.message` 给助手回答附加了 UI 关联字段 `display_call_id`，原始 Agent context 没有该字段；以完整对象哈希求交集时，助手回答全部被排除。现在仅在来源身份匹配时忽略此显示字段，仍匹配完整其余内容并限制相同会话与事件类型；模型材料保留原日志 event ID、source ref，原始对象不改写。新增回归让承诺只出现在助手回答中，并同时验证无关内容、其他会话事件仍被排除。两种摘要提示也明确新承诺须逐字进入结构字段，写在摘要或 goals 不等同于记入账本；原有来源校验及关闭条件保持不变。

设置重建摘要曾把 `expected_revision` 解释为当前生效版本；该值实际是提交前的 CAS 前置版本。模型可见的设置说明现在只携带新指令内容；持久提交负载仍保留原 CAS 条件，真实生效版本继续由 Host 的上下文元数据提供。定向集成测试同时检查三者，基线失败、修复后通过。两类摘要提示均要求保留条件和作用域，避免将条件偏好简化成无条件禁令。

安全渲染的独立审查发现未闭合链接与不等长反引号串的重复扫描；缩窄匹配边界后，增加大输入耗时与原文保留回归。在线报告新增完成门槛，运行中的证据不能标记为最终通过；字段 oracle、承诺账本检查与自然语言人工复核保持独立。

来源修复后的独立真实模型复测仍出现完整承诺在摘要中、结构字段为空的失败。针对这一失败，整理与设置重建在全部承诺字段为空时增加一次独立真实模型提取，只允许最多 16 条、每条最多 1200 字符的完整原文引句；不开放工具，不做提取内部重试（生产原有外层最多两次摘要 attempt，每次可触发一次提取），输出预算最多 4096 token。候选继续经原有 Host 来源校验后才能进入账本，既有承诺不能被遗漏删除。Host 在新增异步调用之后重新检查上下文、修订号及新输入边界，防止保存过期候选。此修复增加必要时的一次调用，不保证模型永远不会漏提取，也不声称检查了非空候选中的所有遗漏。

独立提取接入后的首轮在线运行又遇到摘要把人的责任方 `MASTER` 写入系统路由字段 `pending_owner`，Host 拒绝了无效结构。提示补全其合法枚举及人类责任的记录位置，未放宽 schema 或自动改写模型结果；失败请求保留。

再次复核发现主摘要虽输出非空承诺字段，但引用的是 Master“要求承诺”的片段，而非助手真实接受的语句；因此非空检查不足以确认语义。最终将新增承诺统一交给专职提取步骤，主摘要字段不再作为新增账本依据。每次成功摘要尝试新增一次提取调用；原有外层最多两次尝试、来源校验及账本关闭条件不变。新增对抗回归覆盖主摘要非空但引用用户请求的情形。专职模型仍可能误判，最终真实模型样本仍人工检查引句、说话者和条件，不宣称字符串匹配能验证全部语义。
