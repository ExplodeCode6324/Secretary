## 实施与验收

1. 私有台账覆盖各阶段的报告输入、盲评、原始恢复材料、历史错误与分母。每组登记归属、来源测试、依赖、大小与处置。对设施查归属标记、控制器、进程和打开文件。凭据和部署数据位于采集范围之外。
2. 缺失的私有导出输入按明确文件清单在本机打成保留相对路径的 tar.gz，检查敏感字段，使用 NAS 唯一目标。回读压缩包并按清单逐文件验证大小和 SHA-256。已有归档也在释放对应源材料前完成核验。冲突路径、链接或哈希均阻断该项。
3. 在空临时目录从 NAS 输入离线重建。用固定版本的正式导出器从私有回执重建历史合并报告并与发布字节对比。从 R79 工作负载与独立评分归档复算补测，绑定 R67 历史补充及未启用评分处置，重建三张覆盖表。比较有效行、摘要、99 个观察、189 个断言位置和 R79 四类计数 95/12/1/81。逐层写明来源、命令、首次失败及零真实调用；保留未覆盖项。
4. 列出逐项释放原因、NAS 恢复位置、摘要及有无依赖。缓存和固件绑定产生它的测试及已停止的源。设施优先使用现有 benchmark 生命周期/归档命令。释放前独占访问，重新核对挂载、路径、活动状态、打开文件与数据漂移，按明确清单操作。依赖、归属或重建校验缺失则保留该项。
5. 分别报告实际移除路径、逻辑字节、已分配块前后差和同期文件系统可用空间变化，注明硬链接、共享块或并发写入影响。释放后在无已删输入的条件下重复报告比对，复查保留位置和回执，登记跳过项及原因。精确本机路径、原始材料和 Claude 日志保存在私有侧，Git 记录脱敏结果。
6. 本轮验证包含离线重建、数据完整性、文档检查和必需 CI。真实模型性能实测属于后续工作。合并另由 Master 授权。
