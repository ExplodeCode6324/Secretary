## 4. `/open` grammar and current-file semantics (R4)

- Ordinary Main only; command name case-insensitive, arguments case-preserving. One ASCII space separates command from payload; the remainder is one literal path with internal spaces/Chinese preserved. No shell quotes/tilde/env/glob/URL expansion or quote stripping. Reject empty, NUL/control/newline and oversized paths. Example: `/OpEn /absolute/中文 目录/Report.txt`.
- Absolute paths locate that local regular file directly. Apply no-links checks and reject directories. To avoid executing Task-written launchers via LaunchServices, reject any execute permission bit and only open document suffixes `.txt .md .csv .tsv .json .yaml .yml .log .pdf .png .jpg .jpeg .gif .webp .docx .xlsx .pptx .odt .ods .odp` (case-insensitive). Other types, including .command/.tool/.terminal/.webloc/.inetloc/.fileloc/.jar/.py, fail locally; no automatic reveal or alternate file. This conservative document-type policy is included in Master's plan approval. It is not a sandbox for arbitrary file associations: a per-file “Open with” association (including resource-fork metadata) can select a launcher even for a permitted suffix, and this has not been tested locally. This specific residual LaunchServices risk is part of Master's approval text. The policy also cannot remove an OS-level check/open race; report the actual local result honestly.
- Use fixed `spawn('/usr/bin/open', [absolutePath], {shell:false})`, 5-second timeout, error/exit handling, existence/type/mode recheck immediately before dispatch. A zero exit means OS handoff accepted, not content-viewed proof; native acceptance verifies content. Add native negative checks for a registered run.command and an executable-bit file: one local error, no launched process.
- Resolve bare relative paths through an **exact Core metadata filter** on GET artifacts: `relative_path=<canonical path>` and optional `execution_id=<full UUID>`, ownership-filtered to the current session. Use an incremental metadata index; filter before snapshot lstat checks, not a client scan of the domain. Page only matches. One distinct source root/path resolves; different roots fail ambiguity and request a full path. No page/selection/cwd fallback. Historical references to the same physical root/path can share one current target; missing bindings never guess.
- Also support `/open --execution <full-execution-uuid> <relative path>`: validate accessible Execution and registered path and use its frozen binding. This source qualifier is not an artifact-ID shortcut; no artifact-ID open is added.
- Both /open and clipboard entries reuse the `tui/clipboard.ts` guard: process.platform=darwin and neither SSH_CONNECTION nor SSH_TTY present. CoreClient already checks the local endpoint identity and loopback address; no claim that a forwarded remote filesystem is supported. Reject unsupported environments explicitly.
- Asynchronous queries/open never block editing. On failure, one local notice expires after **5 seconds or the next user action, whichever first**; a token prevents stale timers clearing newer notices. No Main messages, Inputs or UI business audit. Consume only an unchanged submitted command snapshot, retain newer edits and all draft materials. TUI/Core continue running.
