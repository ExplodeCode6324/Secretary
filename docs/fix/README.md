# 修复计划与实施记录

本目录按日期保存修复范围、确认决定、实施过程和验证结果。当前工作顺序以[项目路线](../../README.md#开发路线)为准，已结束计划作为版本记录保留。

Core 工作在 secretary-core 主工作目录中以分支区分，计划统一放在 docs/fix。文件名为 `fix_YYYYMMDD_issueN_具体功能描述.md`，无 Issue 时省略 issueN；日期使用计划建立日。

新计划写明目标和提交基线、源码现状、方案与涉及文件、实施顺序、验收标准、具体风险及执行记录。需要计划确认的任务在确认后实施；Master 已直接授权的修改同步记录执行范围。进度使用待确认、已批准、实施中、待验收、已完成，附实际证据。

历史正文中的命令、指纹和结论保留当时含义，当前行为在对应手册更新。
