| recall | 捕获的最新 MainPromptSnapshot.recall_ref，仅模式/数量；描述那一次 prompt，不代表当前环境 |
| 请求大小/容量 | 既有 Context.request_budget/count_method、model.payload 标量事实、capacity_blocked sent=false；不改估算器 |

现有 `/memory` 会遍历 jobs/extractions，不为填报告主动调用；但下述捕获前两次静默门槛各允许一次 memory GET，用于维护/补提状态，不成为 AG-03 轮询；core status 只能证明身份/运行态，没有检索 ready 字段。不模型调用、不强制维护/补提/重建、不修复数据、不加接口。报告前后快照散列不变证明输入未写；正常 live 可能写入，不能要求 live journal 静止或把重启产生的业务变化归罪于诊断。
