## 4. Shared read-only snapshot reader

AG-02/03 consume a successfully captured manifest and immutable copy. They do not connect to PG or HTTP, instantiate Store/Host/MemorySearch, replay business commands, call models or hydrate arbitrary private prompt text. Read journal frames as files: validate framing/base64/SHA, contiguous sequence/previous digest, transaction shape and revision links; retain latest required records keyed by `(record_type,id)` and the minimal creation/decision event metadata needed. CAS references require canonical `objects/<sha256>`, no symlink/path escape, exact size/hash. Unknown versions, malformed trailing lines, missing references and corrupt chains produce explicit failure/incomplete reports; never silently truncate a journal into an apparently complete result.

Capture contracts.schema.json separately as inert metadata with its hash (in addition to source.tar). Use built-in file/crypto APIs plus that captured version of the existing JSON schema as data, validated with the already installed Ajv dependency (not built-in Node alone), never operational module constructors. Reuse types/format knowledge without creating a second ledger. Recognize message-ref/image-evidence envelopes; avoid decoding image bodies for metrics. If logical byte size would require unsupported/beyond-limit reconstruction, return unavailable; physical CAS size is never labelled request size.

Default hard read budgets: 64 MiB journal, 64 MiB single decoded record, 256 MiB total CAS reads, 100,000 mutations, 30 seconds, 1 MiB output, 200 detail rows. Every mutation snapshot is a CAS read and counts toward the budget. Stream lines with a bounded line buffer and cache bounded metadata, not all private bodies. The reader validates framing/refs/revision links, not all Store.stage business invariants (World/Scope admission, state transitions, guidance, lineage); label it static read projection, never successful Core replay. Report limits/consumption, scanned interval, selected interval, sampling times and truncation. Time/task filters select results; they do not promise indexed journal reads. On hitting a budget, fail closed for exact/global totals and final-state counts; partial diagnostics may be explicitly labelled `INCOMPLETE`, never presented as zeros/full results. Larger explicit limits require an operator rerun, not silent expansion. No recurring TUI refresh/Core tick integration.

## 5. AG-02 measurement contract

For COMPACTION, Context.loop_id matching MemoryExtractionJob.id derives EXTRACTION; matching CompactionJob.id derives COMPACTION; a SettingsApplication match derives SETTINGS_MAINTENANCE; otherwise COMPACTION_UNATTRIBUTED. Job identities, not prompt text, determine subtypes. memory-summary.ts:230 confirms summary loopID = job.id; retain unknown for any unverified route. Retried attempts on different days belong to their own attempt days; logical calls are attributed to their first recorded attempt, with partial-window flags.

Count unique ModelCall IDs as recorded transport attempts, PREPARED separately; latest saved state distinguishes RESPONSE_SAVED, FAILED, INTERRUPTED, unresolved IN_FLIGHT. Logical calls group by logical_key within domain, falling back to call ID with `identity_unavailable`. Saved successes count once per call ID, regardless of journal revisions, recovery playback or duplicate model.response events. Do **not** deduplicate unrelated calls by equal response content/hash. Detect anomalous multiple successes per logical key, report separately and retain their physical response usages rather than suppressing evidence.

**Exact physical HTTP sends are unavailable in this baseline.** transport.ts persists IN_FLIGHT before invoking the stream; cancellation/local payload validation can fail before fetch. model.payload also precedes fetch. Group exact repeated requests by recorded action, resource, full scope, expected_resource_revision and parameters_hash; verify parameter CAS hash, use exact recorded serialized bytes, do not normalize JSON/shell or include random intent_id in equality. Missing material means unavailable. Report repeated group sizes and extra request count, splitting Operation.retry_of-linked retries from independent repeats; never recommend auto-approval.
