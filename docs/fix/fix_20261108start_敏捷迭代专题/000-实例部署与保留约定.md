## 实例结构与使用

- `data/core/`：唯一 live Core 的 journal、CAS、工作区和日志。
- `data/postgres/`：专用持久 PostgreSQL 集群；数据库 `secretary_agile`，端口 55488，仅本目录私有 Unix socket，无 TCP 监听。
- `data/tui/`：同一实例的永久客户端草稿、附件暂存和恢复材料。
- `.local/`：私有 DeepSeek 凭据、运行配置和部署证据，Git 忽略；复用本机现有 DeepSeek 凭据，Main/Task 均使用 deepseek-flash。
- `scripts/agile.mjs`：固定上述路径，清除继承的 SECRETARY 环境变量，防止误连旧实例；不创建分轮数据目录。

双击根目录 `启动Secretary.command` 启动 Core 并连接 TUI；`停止Secretary.command` 停止 Core。关闭 TUI 不停止 Core。也可运行 `npm start`、`npm run tui`、`npm run core -- status`、`npm run stop`。PostgreSQL 随首次启动拉起，停止 Core 后保留运行。旧 src Finder 入口也已转接到同一实例。
