## 人物优化

来源：Master 提供的 `FC16A300-46C4-4EAA-A7B2-43C5612414F1.PNG`。原图保留不改。

原设定有银白偏紫的长发、柔和脸型、宽松白色连帽衫、编结光环，以及月蓝/日金眼睛的视觉语言。参考包的大黑色眼底与夸张符号遮盖自然眼形，亮部点阵过密，头发和脸部层次不足。

1. 大窗口首选头肩构图，保留完整光环、头顶轮廓、脸和少量衣领，避免为了塞入全身而把五官缩成噪点。
2. 先保证发型剪影、脸形与双眼比例，再表达发束、刘海和衣领；减少零散星点、背景残留和无意义抖动。
3. 去掉参考包的大面积黑圆眼底。采用自然眼睑、较小虹膜和高光；以原图下方左右眼特写为色彩依据，月蓝与日金各一眼作为首版拟定方案。月牙/太阳仅在分辨率足够时做细小暗示，不强行放大。
4. 银紫色为主体，琥珀色集中在眼睛的小面积强调；编结光环控制宽高与亮度，能看出交叠与留空，避免盖过人物。
5. 对点阵做按字符网格的轮廓修整与调色，而非只提高图片阈值。提交可再生成的源素材说明、参数及字符资产；不依赖 Downloads 的绝对路径作为运行条件。
6. 实施后提供真实渲染的启动页和对话截图。Master 看首版后指导微调；未实际展示和验收前不宣称人物审美通过。

## 必须补齐的工程适配

1. **敏捷入口**：让通用 CLI 和 `scripts/agile.mjs tui` 都显式启用首版启动页与活动提示。视觉选项采用小范围白名单（颜色、启动页、动效），其余运行域与凭据变量继续按原逻辑清理。
2. **真实状态**：连接、会话与活动使用当前数据；模型名只在真实、可靠且无需暴露凭据的来源可得时显示。当前 Core 返回不含参考预览中的 models；不通过类型强转或写死示例名称假装已有该字段，不为装饰扩展后端 API。
3. **启动页输入**：第一下文字、中文输入、粘贴和命令照常进入现有处理链，终端能力回复和鼠标移动不能误关闭启动页；实际 Main 活动可让位给对话，后台 Task 不误判为 Main 忙碌。
4. **布局高度**：依据实际可用区域处理输入框扩高、附件、恢复提示、事项面板和 resize，修正参考包固定减行估算的不足。重要恢复/错误信息优先于人物展示。
5. **消息源映射**：边框属于装饰；逐行映射、选择复制、中文换行、代码块、长正文窗口和历史锚点必须保持正确。参考包声称行映射不变，仍需实际回归。
6. **动效生命周期**：只在可见且确有活动时启动刷新；空闲、隐藏、断连及退出时停止；不能打断选择拖拽、制造持续无效重绘或显示陈旧进度。
7. **颜色完整性**：统一新增组件、编辑器分隔和页脚的适用色彩路径；参考包预览手绘的蓝色分隔不代表真实编辑器已接入。检查无色模式下 Markdown 等既有硬编码样式，并保持错误/批准/拒绝语义清晰。

拟涉及 `src/pi_secretary/src/tui/` 的主题、启动页、活动提示、view/app/input 等相关组件，两个启动入口，构建期字符素材脚本与预览脚本，以及必要测试和文档。按实际需要最小修改，不调整 Core、数据库、模型请求及任务执行逻辑。
