## 4. AG-02：用量与审批的只读报告

### 工作项

- 按日、Task/Execution、模型角色汇总现有记录。能区分时分开Main、Task、维护；不能区分时标明未能归类。
- 展示物理发送/成功调用/失败尝试、已有输入输出usage与缺失量。重试与恢复不重复计算同一条成功响应；缺失不记为零。
- 价格元数据有明确来源和版本才显示估算费用；没有价格就只报token。费用、累计usage与单次Context占用是三种量，不互相替代。
- 统计授权请求数、等待时长（仅有记录时）、既有remembered rule使用情况和参数完全相同的重复审批。相同指记录参数的精确匹配，不用模型做语义合并，不自动批准或建议扩大权限。
- 显式按需执行，允许时间/任务筛选，避免在TUI每次刷新/Core tick时扫全历史；记录读取量、耗时、范围和结果截断。报表输出不能重写原账本或驱动业务。

### 验收

- [ ] 选定小样本的汇总与原记录逐条对上，物理尝试、逻辑调用、成功响应去重口径明确。
- [ ] 缺失usage/价格/等待数据可见，无凭据或私人原文泄露。
- [ ] 授权、任务、Core状态不变；不新增burn guard、自动暂停、请求预算、重试或信任profile。

- [ ] 能区分来源缺失、维护失败/落后、检索不可用和容量压力；无法观察的项明确列出。
- [ ] 报告有采样边界/读取方法/耗时/大小，既有轻量status不引入重扫描。
- [ ] 运行前后业务记录不因诊断改变；任何必要Core instrumentation移交第二阶段。
