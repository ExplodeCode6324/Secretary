Master 于 2026-11-14 批准实施和短暂停机。工作分支 `codex/agile005-readonly-diagnostics`，PR 目标 `agile`。正式目录保持 `agile`，工具从独立源码 clone 运行。准确 HEAD 的 CI 和实施复核结果登记在 PR；合并仍需另行授权。

## 运行顺序

1. 正常关闭 TUI 保存状态。本轮停机授权允许向准确 TUI 进程发送其已有的正常 SIGTERM 关闭信号，不强杀、不清空草稿。核对运行源码等价性、工具 SHA 和原实例身份；已有维护标记或 Core 原本停止时拒绝采集。
2. 私有 inventory JSON 的 `data`、`.local` 必须列出每个直接子项，分别标为 `frozen`、`operational`、`logical_postgres` 或 `socket_metadata`。Core、TUI、配置和旧复核证据冻结；`data/postgres` 逻辑导出；`data/pgsocket` 只保留元数据；PG/supervisor 活动日志（含 `data/world-postgres.log`）单独带时间采样。未知条目拒绝。当前工具拒绝已注册外部 Scope 和冻结目录中的符号链接，需复核扩展后才支持映射，不猜路径。
3. 使用规范绝对路径：ROOT 为唯一真实实例，TOOL 为复核后的源码 clone，CONTROL/BACKUP 为实例外的私有目录，CONTROL 也必须在 BACKUP 外。以下为占位命令，需填写实际路径：

```sh
node "$TOOL/scripts/agile-diagnostics/capture.mjs" preflight --root "$ROOT" --inventory "$CONTROL/inventory.json" --output "$CONTROL/preflight.json"
node "$TOOL/scripts/agile-diagnostics/capture.mjs" capture --preflight "$CONTROL/preflight.json" --capture-id "$CAPTURE_ID" --inventory "$CONTROL/inventory.json" --backup "$BACKUP" --state "$CONTROL/phase.json"
```

preflight 的 capture ID 五分钟内有效。第二条作为受监督的后台进程运行，保存 PID 和私有输出，避免工具超时终止。`phase.json` 每次阶段变更 fsync。P0 创建专属 marker，等待至少 35 秒无可写启动链，再执行第二次有界静默检查；同秒 ensure 按旧进程处理，后启动的 start-live/core-cli/start 仍视为可写。P1 停止 Core 并等待原 owner/helper 进程树退出，持有已有 Core 和真实嵌套 TUI 锁；P2 在 PG 持续运行下导出；P3 复制和封存；P4 释放锁并恢复原服务。固定 Node 和最小环境调用现有 agile 生命周期入口。源码、Git、依赖和未跟踪静态材料提前装入 `source.tar`，副本 `instance/` 不展开启动器。

4. 失败恢复：

```sh
node "$TOOL/scripts/agile-diagnostics/capture.mjs" recover --state "$CONTROL/phase.json"
```

协调锁防止与尚存 coordinator 同时恢复。P0 仅移除自己的 marker 并检查原 Core；停机后先确认原 owner 退出，不启动竞争实例。外来 marker 或 PG 身份变化阻止自动启动。现有 stop 重写 marker 的狭窄窗口只凭记录的 inode、时间和指定内容接管。SIGINT/TERM/HUP 使用同一恢复路径；SIGKILL 需显式运行恢复命令。目标停机后捕获期限 180 秒、恢复预算 90 秒，不声称卡死进程下仍能保证停机硬上限。`RECOVERY_FAILED` 需人工处理后再决定启动；绝不回灌旧业务数据。

5. 完成须有 `CAPTURED` manifest：原 domain/session、新 Core instance、PG 进程与二进制未换、journal 前缀连续、文件/源码归档/CAS 校验及 `pg_restore --list`。`maintenance-transitions.json` 私下列出窗口内新增的中断/取消/失败，不声称因果关系。副本 `.local/maintenance.json` 设置 `uchg`，仅防误启动，不能防操作者故意绕过。
6. 报告输出在副本及正式 data 根之外，独占创建、0600：

```sh
node "$TOOL/scripts/agile-diagnostics/report.mjs" usage --snapshot "$BACKUP" --output "$CONTROL/usage.json"
node "$TOOL/scripts/agile-diagnostics/report.mjs" memory --snapshot "$BACKUP" --output "$CONTROL/memory.json"
```

usage 可加 `--from`、`--to`（ISO，左闭右开）、`--timezone`（默认香港）、`--task`、`--execution`。显式上调读取预算可用 `--max-journal-bytes`、`--max-cas-bytes`、`--max-milliseconds`。默认 journal/单条记录 64 MiB、CAS 总读取 256 MiB（含每个 mutation snapshot）、10 万 mutation、30 秒、输出 1 MiB、明细 200 组。筛选不免除历史扫描。损坏、缺失、截断或超预算返回 INCOMPLETE，不生成假的全局总数。报表不导入 Core/Store/Host，不连接 HTTP、DB 或模型。

## 数据口径

- 尝试按 ModelCall 身份；started 与 payload 均早于真实 fetch，**物理发送次数和价格不可用**。每个调用只取最新 response；保存的中断响应也计 usage。不同调用的相同响应内容不合并。各 token 字段分已知、缺失、字面零；同逻辑身份多个成功保留用量并报异常。
- 授权等待取首次创建到首次记录决定，撤销/消费不重置。过期仍 PENDING 单列为推断，非真实决定。重复按 action/resource/完整 scope/revision/序列化参数精确 hash，分 retry_of 与独立重复。统计不改变授权。
- 记忆字段逐项记录来源、观测/副本时间、方法和可用性。维护按首次插入顺序；extraction 复用 memoryStatus 条件。checkpoint 的来源、策略、digest 分开；不扫描实际数量，也不据部分匹配宣称检索就绪。recall 仅是上次提示的历史状态；请求预算不是累计账单或字节数。
- 读取器校验 frame/schema/引用/revision，不替代完整业务 replay。已知 message/image envelope 检查引用但不还原图像，不声称可重构逻辑请求大小。源码归档保留字节、mode 和链接；未声明恢复 macOS 扩展属性/resource fork。socket/FIFO 仅元数据。
- 私下逐条对照最多 20 个真实调用/授权。没有 Task/审批样本时明确写无观测，仅用合成测试覆盖对应分支。公开样例只能合成，不公开真实提示、错误原文或参数。

## 恢复草案：NOT_TESTED

保留新写入，另行批准恢复目标与停机。使用匹配源码、Node/依赖、兼容 PG 和 pg_trgm，只在明确测试自有空集群初始化；审核 globals/角色/配置，恢复 custom dump，再恢复 Core/TUI/配置及原 request 身份。重绑定全部指向生产的绝对路径，按支持的所有权流程处理旧 endpoint/锁，仅在获批恢复目标解除 uchg，不解封原始留存备份。完整启动恢复、语义 replay 和异地灾备不在本次证明范围；本机不启动第二个 Core/PG。

## 验证与首次失败

本机执行类型/文档检查、新 mjs 语法、Python 编译及 `node --import tsx --test test_case/offline/agile-diagnostics/*.test.ts`。首次失败来自合成夹具：macOS `/var` 别名、Digest/UserInstructions/审批字段不符合同，以及 message envelope 放错 Context 字段；修正夹具，没有放松生产合同。目前 46 个测试覆盖汇总筛选、损坏/预算/输出路径、envelope 引用、阶段失败与恢复顺序、静默门槛、启动竞争分类及合成文件上的真实 OS 排他锁。

CI 另跑 Linux 全套及 macOS 回归。真实 Store 对照放独立 `agile-diagnostics-ci/`，无 CI 环境时跳过，不使用 agile 域。本机 mock 不等于真实 PG 故障或所有 supervisor 交错验证。完整恢复、真实模型连通、原生 IME/UI、记忆 benchmark 仍 NOT_TESTED。实际采集/报告结果在 CI 和实施复核后记录，不提前算完成。
