## 实施

1. 增加独立 Opus 评估封装与明确 policy，普通 CLI 批次导出默认 Opus。复用校验、冻结控制题、归属/停止检查、租约及追加事务。旧 Fable 白名单和六批迁移锚点保持严格。v3 证据 payload 字节不变，外层评分员和指令明确 Opus，不让旧字段引导伪报 Fable。
2. 每次评估独立不可变命名空间，绑定源包、批次及私有映射哈希。公开请求不含隐藏控制答案。发送前保存请求和发送记录；导入保存原始回复、规范化字节、浏览器模型/上下文观察、哈希及校验结果。禁止替换回复、重复导入已接受批次、重复 ID、伪造元数据、坏哈希及控制失败入选。机械失败保留，不自动语义重试；未完成事务阻止读取，使用既有恢复机制。可信本地操作者观察不是远端模型身份的密码学证明。
3. 增加确定性的选择 manifest 和报告命令。每条可评分轨迹只选一个已绑定哈希的 Opus 回执；缺失、重复和来源漂移不能静默回退 Fable。已有 9 条通过旧严格链路复用；另外 19 条按原九批分组串行全新 Opus 会话评分。首次发送前冻结完整工作清单及选择规则，不因结果挑样、拆批或重试。
4. 主报告列出原始 30 条、可评分 28 条、完全排除 2 条；完成后 28 条全部选用 Opus。保留模型、家族、profile、protocol 分母及全部断言、源回执、失败/跳过/未测。旧迁移封装与新评估封装的来源仍分列，同一评分员不代表统计等价、稳定性或独立性。不生成总资格门槛或排名。
5. 补紧凑中英文操作说明及交付报告。可复现指固定已接受输入、代码/config/源哈希后，无浏览器、凭据或新模型请求即可确定性校验和生成报告；不承诺重新调用 LLM/SUT 的字节确定性。保留 P 官方评分未运行/组件适配、S 生命周期及 R 授权边界。

## R24 处置与 R25 澄清

C1 采纳：“新封装”仅指本地评估存储/绑定，不改模型看到的评分合同。完整复用 `deriveMigrationPayload`：内层证据、rubric、控制字节不变，按已接受迁移精确转换两处指令身份及外层 expected_judge。浏览器只见 `{batch_id,payload_sha256,payload}` 和原 migration wrapper，私有映射、执行证明、工作清单不发送。新本地 record 标识新存储；模型可见版本/policy/指令保持现有 Opus 合同。对六个旧父批次使用原 child ID 纯派生，必须逐字节重现六个已锚定请求哈希，不使用覆盖解释指令，不重发已有 Opus。

C2 采纳：代码/fixture → 独立归属副本纯派生与导出准备 → 提交仅含不透明选择清单/工作清单/准备事务/请求哈希的 anchor → 准确 HEAD 复核及 CI → 持租约源检查并重现锚定字节的真实导出 → 串行发送。新版本执行证明绑定干净 HEAD、review 哈希和 CI URL，预留/发送均核验。九个请求与准备哈希在实施复核前固定。后续源提交需要新的复核执行上下文。后续 cohort 复用通用格式，不硬编码本次数量或 ID。

C3 采纳：每批最多三次永久计数预留。仅确认无回复的传输失败或导入器格式拒绝可原样完整重试；已接受、语义或控制失败不重试。明确接受、校准失败、身份/schema 终止拒绝、耗尽和额度暂停；未接受行显示未评及原因，报告 INCOMPLETE，绝不回退 Fable。校准失败或耗尽暂停实际评分；重分组须另行复核预先规则并一致覆盖相关批次。原四轨迹批次超过此前 Opus 最大三条，历史 Fable 第六批有长度重试，保留风险。R13 控制失败仍阻塞；规则/证据矛盾或新投影不对称记录为测量限制，不阻塞 benchmark 交付；不暗改语义或人工判断。

C4 采纳：私有 replay 输入 manifest 固定所有必需包、映射、原始/规范化回复、回执、journal、ready、config 及代码绑定。命令先检查全部输入哈希再生成报告。首次新发送前，历史不可变清单扩展至已有 Opus child/ready/回执/journal，不仅 377 个原文件。交付后继续保留重放输入；若归档释放，必须 tar/NAS 逐文件校验且先证明恢复副本可重放。公开 Git/PR 只放脱敏汇总与哈希。报告无当前时间字段，执行时间另置回执；重放不需浏览器、凭据、网络或模型调用。

C5 采纳：cohort 与模型/家族/profile/protocol/来源一起作为分组键，不生成跨 cohort 性能汇总；选择式报告另立版本，旧报告不变。

其余有限默认调整：CLI 不再新建 Fable 批次请求，旧读取兼容。公共 QA adapter 未来默认另名 Opus 变体，保留旧 Fable 数据和上游模板/parser；不新增公共 QA 调用或官方评分，也不改变记忆 rubric v3。操作说明列出停止/租约规则、事务残留暂停保留、oracle 树禁写 OS 元数据和两条独立 no-shell 回执引用；保留 CI 首次失败与耗时余量。新旧标签并列仅为同轨迹不同评分员历史描述，不证明一致性或稳定性。
