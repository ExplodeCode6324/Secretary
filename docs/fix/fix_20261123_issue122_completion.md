### C16 按实际分支验收

每次重复都须取得两次覆盖推进的普通提交、实际 Main Context 中的原始输入已退出、同数据域真实重启见证，并绑定重启后首个完整合格请求、相关纠正事实在四个表面的可见性和实际最终结果。以重启前已绑定的原始事件引用及摘要，独立测试重启后的读取结果。先封存自然轨迹证据或记录最终 journal 摘要，再对保存的状态做宿主诊断。诊断回执与 SUT 工具使用分列，结果不回灌试验。若已完成且绑定正确的诊断确证原证丢失，其余必需见证齐备时，该重复以实测的持久性 FAIL 结束。诊断缺失、未能执行或结果不确定，继续阻塞证据验收。

- **常驻。** 原始输入已退出，而合法可见表面仍携带足够的纠正信息。分别判维护传递的准确性和最终回答的使用，冷检索分支记未触发。观测到的常驻使用结果和独立原引用核验可以完成这一分支。
- **确实冷。** 四个表面的缺席得到证明后，按自然探针的实际检索行为评分。通过须有绑定原事件的工具读取、同调用链收到匹配结果，以及有据的最终使用。完整抓取证明漏读、错读或回答无依据，均形成可测的行为失败。独立原引用核验分列，保留实际错误结果。
- **不透明或证据不全。** 可见性不透明，缺少请求、journal、OS 见证或最终结果，或原引用诊断仍不确定时，C16 必需证据仍未齐备。三次计划重复各自保留首次尝试与结果。任何额外尝试或配方变更另作前瞻决策。每个必需重复都要有结构见证和可判定的实际分支才能提交合并，报告包括行为失败，实际冷读取和常驻传递分列。
