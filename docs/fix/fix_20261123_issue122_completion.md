## 对照单元与范围

本期建议用 DeepSeek Flash 单模型建立 Secretary 基线。冻结各角色实际服务版本、provider、模型 ID、端点、生成设置、日期、返回标识和价格依据。显式配置模型，保留扩展能力。GPT 对照为选项。原三模型运行、分数、首次失败、配额与 C16 延期决定按原版本保存，新重复计数为零。后续架构沿用本期对照合同；接入另一个架构属于后续实验。

每条观测记录架构及版本、模型及各角色配置、容量、场景、重复编号、外部输入与哈希、独立源轨迹、配对关系、评分者版本与规则。共同条件包括任务、探针措辞、能力与观测规则。另记各架构实际提示词、维护、工具、预算与事件链的差异。同模型、同服务版本、同容量条件内比较，不匹配者分列。后续按外部场景、配方、种子和重复编号配对，每个架构创建独立新域。供应商无法保证采样可复现时，种子仅描述宿主输入。报告配对结果、完整分母与缺失情况；本期只形成 Secretary 基线。

从 baselineCases(true) 和现有常驻 B 对照生成矩阵。建议每组保留三个新重复，恢复 C16 后，单模型每轮有 33 个候选观测、31 条源轨迹，合计 99 个观测、93 条源轨迹。沿用 C02/C05 配对单源和只恢复一次的合同，C04 对照独立，C16 有三条专用轨迹。数量按每个场景指定一种容量计算，另行批准的多配置重复另计。六家族覆盖表保留 C12a 历史复用、能力/设施排除及原因。依 #122，M4/C15 的时钟依赖评估由 #125 承接。C16 为本期必做。

## 真实冻结前实施

1. 为阶段 C 前瞻规划、派发、报告与兼容读取设新版本。保留封存 offline-v1 投影，按历史字段形状及生产者区分已改名字段，用历史样例验证。新版本分列模板与实际执行输入哈希、架构与模型身份、物理观测、语义判定及缺口。矩阵、预测与派发读取同一不可变描述符。旧九槽批准不得触发任何外部请求。
2. 通过实际入口验证所有本期可运行时间线，使用设施自有域、普通产品准入、CAS/journal 绑定、实际请求抓取及宿主副作用证据。逐动作、路由与配对核对可执行驱动及场景专用断言。驱动缺失、见证缺失、效果不确定和不能评分分别记录。复用 C05-W、C10 已核验原例。C06 统一普通维护及首发截止判据，只发一个自然探针，核对四个表面，分判维护与使用。C08/C09 的字节、权威和事项血缘分列；缺稳定 ID 时血缘标未测。C07/C10/C11/C13/C14 保留真实 Task、反馈与审批绑定。
3. C12b 对文件与 CAS 字节相符的每次完成写入，按实际摘要落账，内容错误或重复写均判 FAIL，包括重启后再次发生。缺少可读证据时效果未决。重启前后都设置有界的归属核验与监督，覆盖卡住的命令、verify-write 和最终封存，清理失败时保留原始首错。补测重启后错误内容、重复写、证据不一致、退出见证缺失、checkpoint 冒充直接重启、新进程挂起与宿主清理。真实观察窗另冻，既有 1.5 秒仅用于合成样例。
4. C16 起始候选沿用 RC98304（Main/Task 窗口 98,304，recent-input 为 2 / 0.05），其余场景默认部署配置。C16 标明缩窗证据，每个场景公开实际配置及外部输入配方供以后配对。先前估计需 181–316 次发送、3,830–6,641 秒，超过旧槽 157 次/3,600 秒限制。根据实际序列化正文、普通维护、上下文退出、重试/工具续轮和已有延迟重算有界预测，先冻结可达配方和充足的显式上限，再运行。改变配置、配方或上限须形成新版本并另批。同一新轨迹取得至少两个覆盖序列推进的独立普通提交、重启前后 Main 实发请求与原始上下文退出证据、同域旧进程退出与新进程启动的独立见证。首个合格探针核查四个表面，分辨常驻、不透明和确实冷；绑定原始事件、读取、结果送达和最终是否有据使用。分开判定原证可查与模型实际行为，区分当前结论、历史与推断。前提齐备时保留模型失败作为基线结果。强制裁剪、模拟退出和延期行均无法满足闭环；缺必需见证继续阻塞合并。

## 冻结、执行与评分

从独立 benchmark checkout 运行，仅使用核验归属的设施及既定隔离凭据，输入为合成材料。复用阶段 B 的派发准入、物理请求预留、计量、崩溃后恢复及封存发布。宿主预期与 SUT 可见输入分离。离线回归从实际新版入口验证无匹配批准时外发为零，来源、行或配方变更均拒绝派发。生成逐槽及汇总冻结表，绑定确定顺序、模型/配置/架构指纹、重复、材料哈希、实测正文大小、请求/时间/token/费用估算、探针与重试在内的所有硬上限、不确定项及预留。按既有时效约定获取新的模型及计费来源。费用预测写明估算依据，真实批准前补齐未知或给出可审计上界。

提交具体冻结表供 Master 批准派发及评分。冻结盲评者身份/版本、规则、对照和批次/尝试上限。用隔离答案键校准，校准失败保留抓取并暂停语义评分。#121 与阶段 B 的既有证据仅在覆盖范围内复用。每个获批槽保存所属轨迹、首次失败、终止原因、回执、原始用量、已知费用及不确定预留；不替换不利结果。C16 提前排序并预留足够资源。中断后遵循同一冻结及幂等合同，预算修订或服务版本变化另行决策。报告保留诊断与各成因，基线失败不授权调整产品。
