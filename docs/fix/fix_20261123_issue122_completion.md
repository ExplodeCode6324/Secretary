## 真实冻结前实施

1. 为阶段 C 前瞻规划、派发、报告与兼容读取设新版本。保留封存 offline-v1 投影，按历史字段形状及生产者区分已改名字段，用历史样例验证。新版本分列模板与实际执行输入哈希、架构与模型身份、物理观测、语义判定及缺口。矩阵、预测与派发读取同一不可变描述符。旧九槽批准不得触发任何外部请求。
2. 通过实际入口验证所有本期可运行时间线，使用设施自有域、普通产品准入、CAS/journal 绑定、实际请求抓取及宿主副作用证据。逐动作、路由与配对核对可执行驱动及场景专用断言。驱动缺失、见证缺失、效果不确定和不能评分分别记录。复用 C05-W、C10 已核验原例。C06 统一普通维护及首发截止判据，只发一个自然探针，核对四个表面，分判维护与使用。C08/C09 的字节、权威和事项血缘分列；缺稳定 ID 时血缘标未测。C07/C10/C11/C13/C14 保留真实 Task、反馈与审批绑定。
3. C12b 对文件与 CAS 字节相符的每次完成写入，按实际摘要落账，内容错误或重复写均判 FAIL，包括重启后再次发生。缺少可读证据时效果未决。重启前后都设置有界的归属核验与监督，覆盖卡住的命令、verify-write 和最终封存，清理失败时保留原始首错。补测重启后错误内容、重复写、证据不一致、退出见证缺失、checkpoint 冒充直接重启、新进程挂起与宿主清理。真实观察窗另冻，既有 1.5 秒仅用于合成样例。
4. C16 起始候选沿用 RC98304（Main/Task 窗口 98,304，recent-input 为 2 / 0.05），其余场景默认部署配置。C16 标明缩窗证据，每个场景公开实际配置及外部输入配方供以后配对。先前估计需 181–316 次发送、3,830–6,641 秒，超过旧槽 157 次/3,600 秒限制。根据实际序列化正文、普通维护、上下文退出、重试/工具续轮和已有延迟重算有界预测，先冻结可达配方和充足的显式上限，再运行。改变配置、配方或上限须形成新版本并另批。同一新轨迹取得至少两个覆盖序列推进的独立普通提交、重启前后 Main 实发请求与原始上下文退出证据、同域旧进程退出与新进程启动的独立见证。首个合格探针核查四个表面，分辨常驻、不透明和确实冷；绑定原始事件，并按下述实际分支核验读取、结果送达及最终使用。分开判定原证可查与模型实际行为，区分当前结论、历史与推断。前提齐备时保留模型失败作为基线结果。强制裁剪、模拟退出和延期行均无法满足闭环；缺必需见证继续阻塞合并。

### C16 按实际分支验收

每次重复都须取得两次覆盖推进的普通提交、实际 Main Context 中的原始输入已退出、同数据域真实重启见证，并绑定重启后首个完整合格请求、相关纠正事实在四个表面的可见性和实际最终结果。以重启前已绑定的原始事件引用及摘要，独立测试重启后的读取结果。先封存自然轨迹证据或记录最终 journal 摘要，再对保存的状态做宿主诊断。诊断回执与 SUT 工具使用分列，结果不回灌试验。若已完成且绑定正确的诊断确证原证丢失，其余必需见证齐备时，该重复以实测的持久性 FAIL 结束。诊断缺失、未能执行或结果不确定，继续阻塞证据验收。

- **常驻。** 原始输入已退出，而合法可见表面仍携带足够的纠正信息。分别判维护传递的准确性和最终回答的使用，冷检索分支记未触发。观测到的常驻使用结果和独立原引用核验可以完成这一分支。
- **确实冷。** 四个表面的缺席得到证明后，按自然探针的实际检索行为评分。通过须有绑定原事件的工具读取、同调用链收到匹配结果，以及有据的最终使用。完整抓取证明漏读、错读或回答无依据，均形成可测的行为失败。独立原引用核验分列，保留实际错误结果。
- **不透明或证据不全。** 可见性不透明，缺少请求、journal、OS 见证或最终结果，或原引用诊断仍不确定时，C16 必需证据仍未齐备。三次计划重复各自保留首次尝试与结果。任何额外尝试或配方变更另作前瞻决策。每个必需重复都要有结构见证和可判定的实际分支才能提交合并，报告包括行为失败，实际冷读取和常驻传递分列。

从独立 benchmark checkout 运行，仅使用核验归属的设施及既定隔离凭据，输入为合成材料。复用阶段 B 的派发准入、物理请求预留、计量、崩溃后恢复及封存发布。宿主预期与 SUT 可见输入分离。离线回归从实际新版入口验证无匹配批准时外发为零，来源、行或配方变更均拒绝派发。生成逐槽及汇总冻结表，绑定确定顺序、模型/配置/架构指纹、重复、材料哈希、实测正文大小、请求/时间/token/费用估算、探针与重试在内的所有硬上限、不确定项及预留。按既有时效约定获取新的模型及计费来源。费用预测写明估算依据，真实批准前补齐未知或给出可审计上界。

提交具体冻结表供 Master 批准派发及评分。冻结盲评者身份/版本、规则、对照和批次/尝试上限。用隔离答案键校准，校准失败保留抓取并暂停语义评分。#121 与阶段 B 的既有证据仅在覆盖范围内复用。每个获批槽保存所属轨迹、首次失败、终止原因、回执、原始用量、已知费用及不确定预留；不替换不利结果。按 93 条源轨迹串行估算总时长，包括三次 C16、校准与来源更新，对照历史 12 小时运行时限及 24 小时资料有效期。若需分批，先提交确定性划分、每批新鲜来源检查和独立批准，保留每个配对源及每条 C16 完整轨迹。C16 提前排序并预留足够资源。中断后遵循同一冻结及幂等合同，预算修订或服务版本变化另行决策。报告保留诊断与各成因，基线失败不授权调整产品。
