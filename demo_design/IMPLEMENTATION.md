# 实施顺序和验收门槛

| 阶段 | 实现内容 | 必须通过的运行检查 |
| --- | --- | --- |
| 1. 契约与存储 | 领域类型、严格解码、状态纯函数、objects/journal、单写锁、恢复 | ACK 后不丢输入；同帧全部生效；尾帧截断恢复；中段损坏阻塞；原字节复载 |
| 2. Scheduler 骨架 | 提案/初始化/前提/触发/分派/取消/保留，先用可控测试 worker | 同 request/occurrence/attempt 不重复；初始化断点恢复；等待不被 TTL 回收；结果先于反馈 |
| 3. 授权与受控程序 | UI 请求通道、规则匹配、最终 gate、程序协议 | 主会话无法批准；参数变更不能复用；撤销/重复点击/消费后崩溃；未知效果停止 |
| 4. World Model | migrations、仓储、实体/来源登记、slot 更正冲突、receipt/outbox | 事务/CAS、证据、时间、类型、冲突保留与 PG/JSON 交接中断 |
| 5. 主会话与记忆 | 主会话有限工具、Context、Consciousness、通知 | 新输入期间不丢请求；工具返回不额外唤醒；部分摘要承接；容量暂停可恢复 |
| 6. 执行 agent | 完整 context 保存/原字节载入、程序恢复协议 | 新进程带同材料续接；不重放历史工具；最终 gate 仍有效 |
| 7. 可用性联调 | 同一界面会话/授权/任务详情、人工程序登记 | Master 实际操作批准/拒绝、任务结果查询、停止恢复；记录 REAL_USE 证据 |

每阶段保留人工停止入口。断点测试可用注入 failpoint + 杀测试子进程，临时数据目录和临时 PostgreSQL；不可破坏真实数据来验证恢复。

本设计已覆盖的静态/SQL验证见 [检查报告](checks/REPORT.md)。运行时的 journal Sync 顺序、文件锁、并发模型调用、HTTP 身份隔离、进程管理、工具副作用与摘要语义质量均需上述实施阶段证明。没有用结构检查代替这些验收。
